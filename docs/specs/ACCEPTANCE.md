# Чек-лист приёмки сайта

Отмечай пункт только после фактической проверки. Нельзя писать «готово», опираясь лишь на наличие исходного кода.

## Чистый старт
- [ ] Удалены старые Next.js/React-пакеты, старые страницы, картинки, компоненты, стили, конфиги и CI; нет следов старого UI.
- [ ] Не созданы backup-копии и отдельные restore-точки.
- [ ] `.git/` и публичный репозиторий остались на месте; историю не переписывали.

## Стек и структура
- [ ] Astro static, TypeScript strict, Tailwind 4 (Vite plugin), npm + package-lock.
- [ ] Нет Next.js, React, серверных адаптеров, backend и CMS.
- [ ] Конфиг и локальные ссылки учитывают корневой base `/`.
- [ ] Понятная структура компонентов, layout, content, config и utils.

## Страницы
- [ ] Главная готова и содержит hero, описание, проекты, блог и ссылки.
- [ ] Список проектов и список статей оформлены и не ломаются без содержимого.
- [ ] Страницы отдельного проекта и статьи собираются по Content Collections при добавлении контента.
- [ ] Теги блога работоспособны, если публикации добавлены.
- [ ] Есть 404 и рабочая навигация во всех разделах.
- [ ] Нет выдуманных кейсов, KPI, отзывов и личных данных.

## Внешний вид и доступность
- [ ] Светлая и тёмная темы, системная по умолчанию, ручной переключатель сохраняет выбор.
- [ ] Нет вспышки неправильной темы на загрузке.
- [ ] Проверены мобильные 360/390/768 и десктоп 1280/1920.
- [ ] Нет горизонтальной прокрутки и обрезанных заголовков.
- [ ] Все интерактивные элементы доступны клавиатурой, фокус видим.
- [ ] Все картинки с корректным alt или помечены декоративными.
- [ ] `prefers-reduced-motion` отключает нефункциональную анимацию.

## SEO и публикация
- [ ] Каждая индексируемая страница имеет уникальный title/description, H1 и правильный canonical.
- [ ] `sitemap-index.xml` или `sitemap.xml` и `robots.txt` есть в `dist` с правильным URL.
- [ ] Все ссылки и ассеты работают на `agubanovv.ru` от корня `/` (включая прямое открытие вложенных страниц).
- [ ] OG-теги и JSON-LD корректны там, где есть достоверные данные.
- [ ] 404 страница существует как `dist/404.html`.
- [ ] Метрика запускается только после действующего явного согласия; отказ, отзыв, изменение версии/срока и запрет хранилища проверены. Clarity и безусловный пиксель отсутствуют.
- [ ] GitHub Pages использует GitHub Actions; push в main после успешных проверок публикует только dist.

- [ ] Политика данных, cookie и отдельное согласие доступны из интерфейса; ФИО и почта оператора подтверждены, формы и рассылки не выдуманы.
