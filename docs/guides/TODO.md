# Отложенные изменения

- Подтверждение владения сайтом в Яндекс.Вебмастере, Search Console и Bing и включение Enforce HTTPS — ручные действия владельца, код их не выполнит. Порядок — в [поисковом руководстве](SEARCH_ENGINES.md).
- По отдельному запросу владельца исправить склейку слов в H1. Проверить пробелы между текстовыми узлами и переносы после автотипографирования. В текущие изменения Telegram, hover и SEO эта задача не входит.
