# Визуальное редактирование: MarkText

Для этого проекта рекомендован [MarkText](https://marktext.me/) — бесплатный локальный редактор для Windows с визуальным оформлением Markdown и таблиц. Текст, заголовки, ссылки и ячейки редактируются в документе; файлы сохраняются в обычном `.md`.

Редактор можно скачать по ссылке Download на официальном сайте. Отдельная установка редактора не добавляет зависимости в сайт. Эта инструкция подготовлена для проекта; сам MarkText агент не устанавливал.

## Что открыть

1. Запустить MarkText и нажать **Ctrl+Shift+O** — открыть папку.
2. Выбрать папку **content** внутри проекта. В боковой панели будут только материалы: SEO-таблица и статьи с изображениями.
3. Для SEO открыть **seo.md**. Визуально менять нужные ячейки Title, Description и ключевых фраз. Адрес в первом столбце связывает строку с конкретной страницей.
4. Для статьи открыть **blog → нужная статья → index.md**. Редактировать текст ниже служебного блока в начале файла. Изображения находятся рядом с текстом, поэтому относительные ссылки работают и в редакторе.
5. Сохранить файл через **Ctrl+S**. Для отдельного файла также доступно **Ctrl+O**.

Режим визуального редактирования включён по умолчанию. Если видна исходная разметка, переключить режим через меню View. Документация редактора: [основные действия](https://marktext.me/docs/basics), [работа с таблицами](https://marktext.me/docs/editing).

## SEO-таблица

Менять содержимое ячейки можно как в обычной таблице. Держите четыре столбца: адрес, Title, Description, ключевые фразы. Не добавляйте форматирование жирным, ссылки или переносы строки внутри SEO-ячеек: это обычные текстовые метаданные.

Разделитель `|` в заголовке редактор может сохранить как `\|`. Сайт понимает и эту стандартную запись, и прежнюю `&#124;`. Формы записи не попадают в метатеги: посетитель увидит обычный символ `|`. Выравнивание столбцов в Markdown не влияет на сайт.

## Статьи

В начале `index.md` находится блок между строками `---`: заголовок, вступление, дата, теги и обложка. Это параметры публикации, их лучше менять с агентом. Обычный текст ниже блока можно редактировать визуально: заголовки, абзацы, списки, ссылки и выделения. Внешний вид редактора отличается от дизайна сайта.

Собственные блоки сайта (`:::заметка`, `:::цитата`, подсказки `{{…}}`) MarkText не знает. Их оформление проверяется в локальном предпросмотре сайта. Ссылки `contact:telegram` и `contact:email` подставляются при сборке; редактор не знает их назначения. Не переименовывайте папку уже опубликованной статьи: её имя задаёт адрес.

## Как увидеть результат на сайте

Сохранение в MarkText меняет локальный исходник. Для просмотра можно попросить агента: «Проверь мои изменения и открой локальный сайт». Агент выполняет проверки и показывает результат. Для публикации нужна отдельная команда владельца.

Черновики и приватные материалы оставляйте вне папки публичного репозитория. В `content/` находятся только готовые публичные материалы.
