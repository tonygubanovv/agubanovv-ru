# Приватность и аналитика

## Реально реализовано

- Форм, авторизации, оплаты, подписок и базы заявок нет.
- Clarity удалён. Метрика 113586660 с Вебвизором и картой кликов — только по явному согласию.
- Узкая полоса во всю ширину снизу, равные разрешение/отказ, ссылку на условия согласия, повторный выбор из подвала.
- Согласие отдельно от политики: `/consent/`. Политика данных `/privacy/`, cookie `/cookies/`.
- localStorage хранит версию, время и решение на 180 дней. Устаревший или неверный выбор не разрешает аналитику. При запрете хранилища решение действует в текущей странице.
- Отзыв останавливает новые обращения, вызывает destruct счётчика, чистит доступные записи Метрики своего домена и перезагружает страницу. Домены Яндекса и уже переданные данные этой кнопкой удалить нельзя.
- Никакого пикселя без JavaScript. На localhost Метрика не стартует.
- При согласии его версия и время передаются в параметрах визита Метрики. Собственного серверного журнала согласий нет; не выдавать это за независимое неизменяемое доказательство.

## Подтверждённые сведения

ФИО и статус владельца подтверждены им лично, используются из `site.legal`. Публичная почта для обращений — `links.privacyEmail`. Другие реквизиты, домашний адрес и документы не добавлялись.

## Что не решается баннером

Наличие/отсутствие обязанности уведомлять РКН, основания обработки, локализация и трансграничная передача оцениваются по фактической схеме и закону. В рамках работы никакие заявления в РКН и договоры от имени владельца не подавались и не заключались. Не обещать полное соответствие праву РФ и не заявлять регистрацию в реестре без подтверждения.

GitHub Pages фиксирует IP посетителя для безопасности. Эта инфраструктурная обработка существует независимо от cookie-баннера. Сайт не переведён на российский хостинг; политику нельзя считать подтверждением локализации данных. Для юридического заключения нужна оценка всей инфраструктуры, а не только фронтенда.

## Проверки

`npm run check`, `npm run build`, затем `npm run smoke`. Smoke проверяет поведение настоящего кода из собранного HTML через изолированное тестовое окружение, не отправляя данные в Метрику. В браузере проверять отказ/повторный выбор, сохранение выбора, мобильный экран, обе темы и переходы на все документы.
