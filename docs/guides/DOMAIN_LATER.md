# Когда подключать собственный домен

Сейчас домен НЕ подключать. Использовать `https://tonygubanovv.github.io/agubanovv-ru/` и `base: '/agubanovv-ru'`.

Когда владелец назовёт реальный домен и разрешит смену:
1. Проверить владение доменом в GitHub (рекомендуется для безопасности).
2. Согласовать предпочтительный вариант с `www` или без `www`.
3. В GitHub Settings -> Pages задать Custom domain и настроить нужные DNS-записи у регистратора, включить Enforce HTTPS после выпуска сертификата.
4. Создать при необходимости `public/CNAME` с ОДНИМ реальным доменом без `https://`.
5. Поменять `site` на `https://реальный-домен`, убрать `base` (сайт станет доступен от `/`).
6. Обновить утилиту ссылок/метаданные, robots, canonical, sitemap, OG, ссылки и ссылки на соцсети при необходимости.
7. Отдельно продумать доступность старых GitHub Pages URL и редиректов; не обещать автоматические 301 без проверки поведения GitHub Pages.
8. Обновить smoke-тест для нового origin/base, проверить внутренние ссылки после деплоя.

Не выполнять эти действия до отдельного запроса владельца.
