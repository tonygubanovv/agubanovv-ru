# Безопасность публичного репозитория — всегда применять

- Репозиторий публичный. Любой добавленный файл, в том числе удалённый позже, мог сохраниться в истории Git. Не загружать туда приватные документы и ключи.
- Перед каждым коммитом проверять `git status --short` и `git diff --cached --name-only` и содержимое изменённых конфигов. Не печатать содержимое секретных файлов в чат и лог.
- Не копировать локальные `.env`, `.env.local`, `*.pem`, `*.key`, `*.p12`, `*.pfx`, локальные настройки агента, файлы с токенами.
- Не сохранять API-ключи в коде, Markdown, data-файлах, GitHub Actions YAML или `PUBLIC_*` переменных.
- Статический сайт на GitHub Pages не обеспечивает серверной тайны: любые данные, переданные в браузер, публичны.
- Любые новые библиотеки оценивать на поддержку, размер, необходимость и лицензию; зависимости фиксируются lock-файлом.
- При обнаружении ранее опубликованного секрета сообщить владельцу о необходимости отозвать и перевыпустить его; не обещать, что удаление файла решает проблему.
- Запрещены `git push --force`, сброс истории, удаление репозитория, изменение DNS и GitHub Settings без отдельного прямого разрешения владельца.
