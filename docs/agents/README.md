Эта папка не является частью сайта и не должна попадать в dist, публичные страницы или sitemap. Публикация загружает только dist; npm run smoke проверяет отсутствие документации, исходного Markdown и ссылок на инструкции в готовом сайте. Репозиторий GitHub остаётся публичным: отсутствие файлов на домене не делает их приватными в GitHub.
