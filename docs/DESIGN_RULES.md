# Правила дизайна и вёрстки

Правила здесь — не пожелания. Каждое из них проверяется скриптом
`scripts/audit-rules.mjs`, `scripts/check-typeset.mjs` или
`scripts/check-content.mjs`, и CI на нарушении
падает. Правило, которое нельзя проверить механически, в этом файле не живёт.

Исключение допускается только осознанное и подписанное: комментарий
`/* rules-allow: <id> — причина */` в том же файле, рядом с нарушением.

## 1. Гарнитура и типографика

| Роль                              | Гарнитура                 | Токен               |
| --------------------------------- | ------------------------- | ------------------- |
| Весь сайт, инструменты и редактор | Onest (variable, OFL-1.1) | `var(--font-onest)` |

- Шрифт подключён локально через `@fontsource-variable/onest`, с кириллицей.
  Никаких `<link>` на чужие CDN: проверка `no-third-party`.
- Единственный источник типографики — `src/styles/typography.css`.
  В компонентах используйте `font: var(--type-<роль>)` и
  `letter-spacing: var(--tracking-<роль>)`. Проверки: `onest-font`, `typography-tokens`.
- `font-synthesis-weight/style: none` включены глобально: браузер не имеет права
  подделывать жирный и курсив на кириллице.
- Роли взяты из Typography.png и адаптированы под сайт: title-1…4,
  subtitle-1…2, body-1…4, акцентные варианты и button-md/sm.
  Трекинг заголовков: −2% для title-1/2, −1,5% для title-3/4.
  У текста и кнопок трекинг нулевой. Интерлиньяж заголовков — 112–125%,
  вводного текста — 150%, основного текста — 160%.
- Токен `--type-*` объединяет вес, размер, интерлиньяж и гарнитуру.
  Не переопределяйте эти части независимо. Для акцента используйте акцентную роль.
  Старой шкалы `--text-*` и алиасов к прежним шрифтам нет.

## 2. Без капслока

Нигде: ни в заголовках, ни в подписях, ни в чипах, ни в метках статусов.
`text-transform: uppercase` и `small-caps` ловит проверка `no-caps`. Различать
уровни иерархии приходится размером, весом и цветом, а не регистром — на
кириллице капслок читается хуже и выглядит как глючная локализация.

## 3. Сетка и адаптивы

Три ступени, планшетных промежуточных нет: `360px`, `1280px`, `1536px`.
Медиазапросы только `@media (min-width: 1280px)` и `(min-width: 1536px)`,
в Tailwind-синтаксисе — `desk:` и `wide:`. Точечные классы `sm/md/lg/xl`
в чужих пресетах запрещены: проверка `breakpoints`.

Базовый поток адаптивный: одна колонка до 1280, дальше — сетки страницы.
Контейнеры: `--container-page` для разделов, `--container-read` (~72ch) для текста.

Размеры фиксированы на каждой ступени. До 1280 px действует
мобильная шкала; отдельного перехода на 768 px нет. Сетки и отступы остаются
гибкими. Новая страница импортирует `Base.astro` и получает токены автоматически.

| Роль               | 360 | 1280 | 1536 |
| ------------------ | --- | ---- | ---- |
| Главный экран      | 36  | 52   | 56   |
| Заголовок страницы | 32  | 44   | 48   |
| Заголовок раздела  | 26  | 32   | 36   |
| Заголовок карточки | 22  | 24   | 26   |
| Основной текст     | 16  | 18   | 18   |

## 4. Движение

- Только `transition`, никаких `@keyframes` и `animation:` — проверка
  `no-keyframes`.
- Максимум: 8px смещения и непрозрачность. Никаких подскоков, параллакса,
  бегущих строк.
- Единая кривая `--ease-glide`, длительности `--duration-fast|base|slow`.
- `prefers-reduced-motion` обнуляет длительности глобально, блок в
  `global.css` — единственное место, где разрешён `!important`.
- Появление секций — `.reveal` + `IntersectionObserver`, 6px и прозрачность.

## 5. Liquid glass

Стекло — `.glass`, один раз на контейнер (шапка, панель фильтров, карточка
контакта), не на каждую карточку. Состав: полупрозрачный фон, `backdrop-filter:
blur + saturate`, тонкая рамка, мягкая тень и одна световая кромка сверху через
`::before`. Если `backdrop-filter` не поддерживается, фон становится плотным
(`--glass-bg-strong`) — вёрстка не должна от этого зависеть.

Зерно (`body::after`) одно на документ, поверх фона, `pointer-events: none`.

## 6. Цвета

Основной акцент: `--c-accent` (`#04585a`) для кнопок, ссылок и выделений.
В тёмной теме он светлее (`#83bab6`). Вторичный цвет `--c-secondary`
(`#c0724e`) используется в ховерах; `--c-secondary-ink` — его читаемый
вариант для текста. Фоны нейтральные: светло-серый `#f5f5f4` и графитовый
`#191b1c`. Зелёным и коричневым большие поверхности не заливаем.

Только токены `--c-*` из `src/styles/global.css`, объявленные в `@theme`
в обеих темах. Литералы `#hex`/`rgb()` вне `global.css` ловит проверка
`no-raw-colors`. Исключение — `<meta name="theme-color>`: он обязан быть
литералом, потому что CSS-токены ещё не загрузились (подписано `rules-allow`).

## 7. Типографика текста

Авто-типограф (`src/lib/typography.ts`) применяется на сборке через
rehype-плагин и в админке для превью — картинка в редакторе равна картинке на
сайте. Единственное железное правило: **типограф имеет право заменить символ
только на его месте**.

Запрещено: вставлять пробел внутрь слова, добавлять или терять цифры и буквы,
разрывать слово неразрывным пробелом, быть неидемпотентным.

Это проверяет `scripts/check-typeset.mjs` на всём корпусе сайта
(`src/lib/**/*.ts`, `src/lib/copy/*.ts`, `src/content/blog/*.md`) плюс набор
заведомо опасных фраз. Падение скрипта блокирует сборку.

Отдельно: замена «е» на «ё» происходит только по словарю точных слов
(`YO_MAP`). Слов, где «е» может быть формой другого слова («все», «ней»), в
словаре нет — ошибка подстановки дороже пропущенной буквы.

## 8. Русский язык в интерфейсе

Вся проза — в `src/lib/copy/*.ts`, ни одной фразы прямо в `.astro`-разметке.
Англицизмы заменяются русским термином, если он существует и понятен читателю:
`payback` → окупаемость, `registry` → реестр значений, `messaging` → сообщения.
Названия параметров (`utm_source`), продуктов (GA4, Telegram Ads) и формулы
в коде остаются как есть.

## 9. Контент

Контракт frontmatter проверяет `audit-rules.mjs`: обязательные `kind`, `title`,
`dek`, `topic`, `date`; для `kind: case` — ещё `context`, `metrics`, `channels`,
`role`. Тот же контракт навязывает админка при публикации, поэтому рассинхрон
между редактором и сборкой невозможен.

Имена клиентов не публикуются никогда: в кейсах остаются условия, действия и
цифры. Посторонние символы (CJK, диакритика) в тексте материалов — ошибка сборки.

## 10. Разметка материала

Заметки, предупреждения, выводы, шаги, сворачиваемые блоки и выносные цитаты
пишутся директивами `:::note[Заголовок]` — не HTML-вставками и не заголовком
через пробел. Набор закрытый: шесть контейнеров и одна inline-директива
`:mark[важное]`; имя вне списка ловит `scripts/check-content.mjs`, и сборка
падает вместе с текстом ошибки, в котором указана строка.

Тот же набор размечает предпросмотр в админке, поэтому расхождение между тем,
что видит редактор, и тем, что стоит на сайте, считается дефектом. Подробности
синтаксиса, таблиц, задач, сносок, подписей к картинкам и якорей — в
`docs/CONTENT_KIT.md`.

## Как проверить локально

```bash
npm run verify      # типограф + дизайн-правила + сборка + валидация контента
```

По отдельности, если нужна только одна проверка:

```bash
npm run check:typeset   # корпус типографа, идемпотентность
npm run check:rules     # дизайн-правила и контракт контента
npm run check           # типы (astro check)
npm run build           # сборка
npm run check:content   # директивы, ссылки, якоря и собранный HTML
```

CI в `.github/workflows/deploy.yml` выполняет те же шаги в том же порядке:
правило, которое не проверяется машиной, в этом проекте правилом не считается.
