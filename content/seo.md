# Метаданные всех страниц

Это рабочая таблица: сайт берёт title, description и keywords прямо отсюда.
Одна строка — один адрес. Title выводится буквально, имя автоматически не дописывается.
Ключевые фразы необязательны: можно оставить ячейку пустой или перечислить через запятую.
Не переносите текст внутри строки таблицы. Для вертикальной черты используйте &#124;.

Старые адреса /privacy/, /cookies/, /consent/ используют строки /legal/…/.
Служебные перенаправления формируются автоматически и не требуют отдельных строк.
