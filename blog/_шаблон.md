Файлы с подчеркиванием в начале имени в блог не попадают, так что этот шаблон можно держать в папке `blog/` и копировать его для каждой новой записи.

## Заголовок второго уровня

Обычный абзац. Строки внутри одного абзаца склеиваются в одну, поэтому перенос строки в середине мысли ничего не ломает. Пустая строка начинает новый абзац.

**Жирный** набор, *курсив*, `код в строке`, [ссылка](https://servicepipe.ru/).

- список
- ещё один пункт
- третий пункт

1. нумерованный
2. второй

> Цитата в несколько строк
> продолжение той же цитаты.

---

Тире на отдельной строке рисует разделитель. Код блокируют три обратные кавычки:

```
SELECT count(*) FROM visits WHERE source = 'direct';
```

Картинка одной строкой: `![описание](/blog/assets/imya.png)`. Сам файл кладётся в `blog/assets/`, сборка переносит его в `web/blog/assets/`. Абзац сразу после картинки оформляется как подпись.

Front matter необязателен: если его нет, заголовком записи становится первая строка вида `# …`, а датой — дата последнего коммита этого файла (а пока файл не закоммичен — дата его изменения). `#`-заголовок в начале текста не дублируется в теле статьи.

Адрес страницы берется из имени файла: `pervaja-zapis.md` откроется по `/blog/pervaja-zapis.html`. Дата из поля `date` влияет на порядок в ленте и пишется по-русски под заголовком.
