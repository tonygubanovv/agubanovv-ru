# Личный сайт Антона Губанова

Статический сайт на Astro: https://agubanovv.ru/. Статьи и кейсы объединены в блоге. Публикация — GitHub Pages, через GitHub Actions.

## Где что менять

| Задача | Файл или папка |
| --- | --- |
| Все title, description и ключевые фразы | [content/seo.md](content/seo.md) — одна рабочая таблица |
| Статья и её изображения | `content/blog/<slug>/`: текст в `index.md`, картинки рядом |
| Общие фотографии | `content/images/` |
| Контакты, имя, тексты главной, меню и рекомендации | [src/config/site.ts](src/config/site.ts) |
| Состав страниц | `src/pages/` |
| Общая оболочка и шаблон статьи | `src/layouts/` |
| Общие элементы: шапка, подвал, карточки | `src/components/` |
| Цвета, размеры и темы | [src/styles/global.css](src/styles/global.css) |

[Подробная карта проекта](docs/guides/PROJECT_MAP.md) объясняет названия папок, связь статей со страницами и порядок добавления материала. [Вся документация](docs/README.md), [как поручать изменения](docs/guides/START_HERE.md), [публикация](docs/guides/PUBLISH.md).

Материалы для редактирования находятся в `content/`, код — в `src/`, инструкции — в `docs/`. Одна статья — одна папка. Например, `content/blog/llms-txt-useless/index.md` создаёт страницу `/blog/llms-txt-useless/`. Вручную делать страницу для каждой новой статьи не нужно.

Title и description берутся из общей SEO-таблицы. Название статьи и вступление — отдельные поля `title` и `summary` внутри её Markdown-файла. SEO-правки не меняют текст на странице и в карточках. Контакты задаются только в объекте `links` в общих настройках; в статьях можно использовать `[Telegram](contact:telegram)` и `[Почта](contact:email)`.

Для правки статей и SEO-таблицы в визуальном редакторе: [MarkText — инструкция для этого проекта](docs/guides/VISUAL_EDITING.md). Все юридические документы находятся в `src/pages/legal/`; старые адреса перечислены в `movedPaths` (`src/utils/routes.ts`) и используют общий шаблон перенаправления.

## Локальный просмотр и проверки

Нужны Node.js 24 LTS и npm. При первой установке выполнить `npm ci`.

- `npm run dev` — разработка, обычно http://127.0.0.1:4321/.
- `npm run check` — проверка Astro, TypeScript и тесты.
- `npm run build` — сборка готового сайта в `dist/`.
- `npm run smoke` — проверка собранного HTML: метаданные, адреса, картинки, ссылки, индексация, согласие на аналитику и отсутствие служебных документов.
- `npm run preview` — локальный просмотр готовой сборки.

`node_modules/`, `.astro/` и `dist/` создаются автоматически. Их руками не редактируют. Изображения обрабатываются Astro: браузер получает подходящий размер, превью соцсетей — JPEG. Весь человекочитаемый текст автоматически проходит Typograf.

## Публикация и безопасность

Правила работы — в [AGENTS.md](docs/agents/AGENTS.md). Не отправлять изменения в GitHub без прямой команды владельца: push в `main` автоматически запускает проверку и публикацию. В репозитории хранятся только публичные материалы; черновики остаются вне проекта.

Контакты, аналитика и правила индексации находятся в `src/config/site.ts`. Метрика запускается только после согласия посетителя. Домен, DNS и настройки поисковых систем описаны в `docs/guides/`.
