# t-gubanov.ru

Личный сайт на Astro с заметками, кейсами, инструментами и браузерной админкой.

Для владельца сайта: [подключить админку без терминала](docs/GITHUB_SETUP.md).
Домен, контакты и репозиторий уже настроены.

```powershell
npm ci
npm run dev
```

Локальный адрес: http://localhost:4321/. Требуется Node.js 22+.

- [Подключение GitHub, публикация и админка](docs/GITHUB_SETUP.md)
- [Токены и правила дизайна](docs/DESIGN_RULES.md)
- [Оформление материалов](docs/CONTENT_KIT.md)

Перед отправкой изменений: `npm run verify` и `npm run check`.
