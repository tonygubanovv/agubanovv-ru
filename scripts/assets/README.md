Onest Regular TTF is used only to generate the social preview as SVG outlines.
It is instantiated at weight 400 with composite outlines decomposed for the renderer.
Source: https://github.com/google/fonts/tree/main/ofl/onest
License: OFL.txt. The website itself loads the WOFF2 subsets from Fontsource.

Regenerate the preview with `node scripts/make-og.mjs`. Colors are read directly
from `src/styles/global.css`; the generator needs no system fonts.
